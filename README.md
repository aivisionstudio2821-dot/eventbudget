# EventBudget — Smart Event Planning & Budgeting Platform

> **“You set the budget. We plan the celebration.”**

EventBudget is an intelligent event-tech platform that turns any celebratory budget and guest list into a realistic, itemized event plan with local Ahmedabad vendor connections and automated rebalancing.

---

## 🚀 Key Features

- **💰 Smart Dynamic Budget Engine**: Automatically allocates funds across Food, Venue, Decoration, DJ/Music, Photography, Miscellaneous, and Emergency Buffer based on event type, guest pressure, and chosen priority.
- **🍽️ Food Menu Builder**: Itemized menu planning with per-plate multipliers, 1-click curated packages (Basic, Standard, Royal), over-budget alerts, and smart cheaper alternative swaps.
- **🎈 Decoration & Theme Planner**: 10 themes with auto-recommended decor items, stage setups, floral arches, and photo booth corners.
- **🎧 DJ & Entertainment**: Sound packages, concert rigs, live dhol players, singers, and special effects.
- **📸 Photography & Film**: Candid, traditional, 4K aerial drone coverage, and viral Instagram reels creator.
- **🏰 Venue & Utilities**: From home setups to 5-star hotel ballrooms + AC, DG power generator, and valet parking add-ons.
- **📍 Ahmedabad Local Vendor Marketplace**: Verified directory with direct `tel:` calls and dynamic pre-filled WhatsApp inquiry generators.
- **💬 Real Quotation Comparison**: Record actual vendor bids, compare price spreads, and use `USE THIS QUOTE` to override estimates with real vendor pricing.
- **⚡ “Fix My Budget” Auto-Rebalancing**: 1-Click AI rebalancing that trims non-priority categories and protects your main priority.
- **📈 5-Pillar Event Health Score (0–100)**: Real-time risk evaluation across budget control, emergency buffer, food planning, priority protection, and vendor quote flexibility.
- **💼 Startup Monetization Architecture**: Built-in business model section covering featured listings, lead fees, booking commissions, vendor SaaS, and host concierge passes.

## 🏆 Shark Tank Competition Demo Flow

1. Click **`⚡ LOAD DEMO EVENT`** (Pre-loads ₹50,000 Ahmedabad Birthday for 50 guests).
2. View **“WHAT CAN I GET IN MY ₹50,000 BUDGET?”** showing the curated breakdown.
3. Switch to **“Replace / Upgrade Demo”** and click **“Apply Upgrade”** (+₹4,000 DJ Lights).
4. System immediately flags: **`⚠️ YOUR EVENT IS NOW ₹4,000 OVER BUDGET`**.
5. Click **`⚡ FIX MY BUDGET`** — the engine automatically rebalances non-priority categories, protects the Food priority, and brings the event back to **`🎉 YOUR EVENT FITS YOUR BUDGET`**.
6. Click **`WhatsApp`** on any Ahmedabad vendor card to test the pre-filled inquiry.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations & FX**: Canvas Confetti, CSS Glassmorphism
- **Currency Engine**: `Intl.NumberFormat('en-IN')`
- **State & Storage**: Browser `localStorage` (Zero backend required)

## 📦 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/aivisionstudio2821-dot/eventbudget.git

# Navigate into directory
cd eventbudget

# Install dependencies
npm install

# Start local dev server
npm run dev

# Run production build
npm run build
```
